# QTensor: Asymmetric Heterogeneous Factorization with Subspace Bridging for Sub-1GB Edge Inference

## Abstract
The deployment of Large Language Models (LLMs) on edge devices is fundamentally bottlenecked by VRAM capacity and memory bandwidth constraints. While uniform compression techniques such as INT4 quantization and Singular Value Decomposition (SVD) offer significant memory reductions, they exhibit severe failure modes when applied homogenously across transformer architectures; notably, uniform SVD on Feed-Forward Network (MLP) layers induces catastrophic vocabulary collapse and loss of non-linear representational capacity. We present QTensor Asymmetric 2.0, a heterogeneous compression framework that abandons uniform topologies. By applying Block-wise SVD exclusively to Attention projections and INT4 quantization strictly to MLP layers, we preserve the critical capabilities of both subsystems. To resolve the resulting residual variance mismatch between the high-precision low-rank attention outputs and the quantized MLP inputs, we introduce a lightweight Rank-1 Subspace Bridge. Executed via a hardware-optimized 64x64 SRAM-blocked Triton kernel, our asymmetric topology achieves 70.27 tokens/sec inference on a 1.1B parameter model while strictly confining the memory footprint to ~1.16 GB of VRAM, demonstrating a viable pathway for high-fidelity, ultra-low resource edge inference.

## Introduction
The rapid scaling of Large Language Models (LLMs) has unlocked unprecedented natural language capabilities, yet their deployment remains stubbornly constrained to cloud infrastructure due to massive memory and compute requirements. Enabling on-device edge inference—where privacy, latency, and connectivity are critical concerns—demands aggressive model compression. However, the pursuit of sub-1GB footprint LLMs is hindered by the memory wall and the inherent limitations of traditional compression techniques.

Uniform compression strategies, which apply a single transformation (e.g., INT4 quantization or low-rank factorization) across all layers of the network, fail to account for the heterogeneous functional roles of distinct transformer components. Applying Singular Value Decomposition (SVD) across the entire network effectively reduces memory bandwidth but induces catastrophic vocabulary collapse within the Feed-Forward Network (MLP) layers, stripping the model of its non-linear representational capacity. Conversely, uniform aggressive quantization often degrades the sensitive multi-head attention mechanisms.

In this paper, we propose an asymmetric, heterogeneous approach to LLM compression. We hypothesize that the optimal compression strategy is not uniform, but rather highly dependent on the sub-architectural component being compressed. We introduce the QTensor Engine (Asymmetric 2.0), a framework that applies Block-wise SVD strictly to the Attention mechanisms—exploiting their inherent low-rank structure—while preserving the vital non-linear transformations of the MLPs via INT4 quantization. Furthermore, we address the architectural challenge of integrating these disparate compression paradigms by introducing a Rank-1 Subspace Bridge, which acts as a distributional adapter to heal residual variance mismatch.

Coupled with a custom, hardware-optimized Triton kernel designed around a 64x64 SRAM blocking strategy to keep decompression strictly on-chip, our topology demonstrates that highly accurate, sub-1GB LLM inference is not only possible but can be achieved with exceptional throughput.
